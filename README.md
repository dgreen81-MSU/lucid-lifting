# Lucid Lifting

A modern fitness, apparel, and personal training website built with React, Vite, and Tailwind CSS.

Lucid Lifting combines premium fitness branding, responsive web design, interactive user experiences, and reusable React components into a polished front-end application.

## Running Locally

Clone the repository

```bash
git clone https://github.com/dgreen81-MSU/lucid-lifting.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Create a production build

```bash
npm run build
```
